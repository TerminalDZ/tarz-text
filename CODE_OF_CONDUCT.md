# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive
feedback, and focus on what is best for the community. Harassment and
abusive behaviour are not tolerated.

Instances of unacceptable behaviour may be reported to the maintainers
through a private message on GitHub (https://github.com/TerminalDZ). All
reports will be reviewed and handled confidentially. Enforcement follows the
Community Impact Guidelines of the Contributor Covenant.
